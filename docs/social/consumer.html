Promise one
We will never
show you a
percentage.

A number like "3.2% chance today" feels precise. It isn't. It's a calendar estimate wearing a lab coat.

And a low number doesn't read as uncertain — it reads as permission. So LunarFlow shows a qualitative range instead, and never uses the word "safe" anywhere near it.

LunarFlow is not a contraceptive method.

How it works
Your method
changes what
we show you.

If your contraception stops ovulation, a fertile window isn't uncertain — it's false. So we take it away entirely.

Window removed

Combined pill · Progestogen-only pill · Hormonal IUD · Implant · Injection · Patch · Ring

Window kept

Copper IUD · Sterilisation · Barrier methods — ovulation continues, so the signal is real

Removing a window that was genuinely there would be its own kind of lie.
